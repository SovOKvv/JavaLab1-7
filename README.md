## Задача 1 (Метод 1): fraction
### Текст задачи
Дробная часть. Дана сигнатура метода: `public double fraction (double x);`. Необходимо реализовать метод таким образом, чтобы он возвращал только дробную часть числа `x`. Подсказка: вещественное число может быть преобразовано к целому путем отбрасывания дробной части.  
*Пример:* `x = 5.25`, результат: `0.25`.

### Алгоритм решения
Для нахождения дробной части вещественного числа `x` используется операция взятия остатка от деления на единицу (`x % 1`). Это позволяет отбросить целую часть числа и вернуть оставшуюся дробную составляющую.

## Задача 4 (Метод 8): isDivisor
### Текст задачи
Делитель. Дана сигнатура метода: `public bool isDivisor (int a, int b);`. Необходимо реализовать метод таким образом, чтобы он возвращал `true`, если любое из принятых чисел делит другое нацело.  
*Пример 1:* `a = 3`, `b = 6`, результат: `true`.  
*Пример 2:* `a = 2`, `b = 15`, результат: `false`.

### Алгоритм решения
Метод проверяет два условия с помощью оператора логического ИЛИ (`||`): делится ли первое число на второе (`a % b == 0`) либо второе на первое (`b % a == 0`). Если хотя бы одно из условий истинно, возвращается `true`.

## Задача 5 (Метод 9): isEqual
### Текст задачи
Равенство. Дана сигнатура метода: `public bool isEqual(int a, int b, int c);`. Необходимо реализовать метод таким образом, чтобы он возвращал `true`, если все три полученных методом числа равны.  
*Пример 1:* `a = 3`, `b = 3`, `c = 3`, результат: `true`.

# Задание 2. Условия
## Задача 1 (Условие 3): is35
### Текст задачи
Тридцать пять. Дана сигнатура метода: `public bool is35 (int x);`. Необходимо реализовать метод таким образом, чтобы он возвращал `true`, если число `x` делится нацело на 3 или 5. При этом, если оно делится и на 3, и на 5, то вернуть надо `false`. Подсказка: оператор `%` позволяет получить остаток от деления.  
*Пример 1:* `x = 5`, результат: `true`.  
*Пример 2:* `x = 8`, результат: `false`.  
*Пример 3:* `x = 15`, результат: `false`.

### Алгоритм решения
Вычисляются два флага: делимость на 3 (`is3 = (x % 3 == 0)`) и делимость на 5 (`is5 = (x % 5 == 0)`). Возвращается результат логического выражения: число должно делиться либо на 3, либо на 5 (`is3 || is5`), но не одновременно на оба числа (`!(is3 && is5)`).

## Задача 2 (Условие 5): max3
### Текст задачи
Тройной максимум. Дана сигнатура метода: `public int max3 (int x, int y, int z);`. Необходимо реализовать метод таким образом, чтобы он возвращал максимальное из трех полученных методом чисел. Подсказка: идеальное решение включает всего две инструкции `if` и не содержит вложенных `if`.  
*Пример 1:* `x = 5`, `y = 7`, `z = 7`, результат: `7`.  
*Пример 2:* `x = 8`, `y = -1`, `z = 4`, результат: `8`.

### Алгоритм решения
В качестве предварительного максимума принимается первое число (`max = x`). Затем последовательно проверяются два условия: если `max < y`, то `max = y`; если `max < z`, то `max = z`. В результате возвращается итоговое значение `max`.

## Задача 3 (Условие 7): sum2
### Текст задачи
Двойная сумма. Дана сигнатура метода: `public int sum2 (int x, int y);`. Необходимо реализовать метод таким образом, чтобы он возвращал сумму чисел `x` и `y`. Однако, если сумма попадает в диапазон от 10 до 19, то надо вернуть число 20.  
*Пример 1:* `x = 5`, `y = 7`, результат: `20`.  
*Пример 2:* `x = 8`, `y = -1`, результат: `7`.

Вычисляется сумма чисел (`sum = x + y`). С помощью условного оператора проверяется, находится ли сумма в диапазоне `[10, 19]`. Если условие верно, значение переменной `sum` принудительно заменяется на 20, после чего возвращается результат.

## Задача 4 (Условие 8): age

Необходимо реализовать метод таким образом, чтобы он возвращал строку, в которой сначала будет число `x`, а затем одно из слов: *год, года, лет*. Слово "год" добавляется, если число оканчивается на 1 (кроме 11); "года" — если на 2, 3 или 4 (кроме 12, 13, 14); "лет" — во всех остальных случаях.

### Алгоритм решения

## Задача 5 (Условие 10): printDays
### Текст задачи
Вывод дней недели. Дана сигнатура метода: `public void printDays (String x);`. Метод принимает строку с названием дня недели и выводит на экран название переданного дня и всех последующих до конца недели дней. Если передан не день, выводится текст `"это не день недели"`. Вместо `if` использовать `switch`.  
*Пример 1:* `x = "четверг"` -> выводит: четверг, пятница, суббота, воскресенье.  
*Пример 2:* `x = "4г"` -> результат: `это не день недели`.

### Алгоритм решения
Используется оператор `switch` по строковому значению дня недели. За счет намеренного отсутствия инструкций `break` в ветках `case` (проваливание `fall-through`), при выборе определенного дня выводятся все последующие дни недели вплоть до завершения работы блока. Для некорректных строк срабатывает секция `default`.

## Задача 3 (Массив 6): reverse
### Текст задачи
Реверс. Дана сигнатура метода: `public void reverse (int[] arr);`. Метод изменяет исходный массив `arr` так, чтобы элементы были записаны задом наперед.  
*Пример:* `arr = [1, 2, 3, 4, 5]`, результат: `arr = [5, 4, 3, 2, 1]`.

### Алгоритм решения
Используются два указателя (`left = 0` и `right = arr.length - 1`). В цикле `while (left < right)` происходит поочередный обмен местами элементов симметричных относительно центра массива с использованием временной переменной `temp`, после чего указатели смещаются навстречу друг другу.

## Задача 5 (Массив 8): concat

Объединение. Дана сигнатура метода: `public int[] concat (int[] arr1, int[] arr2);`. Метод возвращает новый массив, в котором сначала идут элементы первого массива (`arr1`), а затем второго (`arr2`).
